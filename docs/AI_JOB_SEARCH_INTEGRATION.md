# Third-party inspiration

Kazi's application workflow is adapted from ideas in
[MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search),
including evaluate-before-apply, job-specific CV tailoring, cover-letter
generation, interview preparation, and the rule that candidate experience must
not be invented.

The upstream project is distributed under the MIT License. Kazi's implementation
uses its own TypeScript domain model and templates rather than embedding the
upstream command-line framework.
